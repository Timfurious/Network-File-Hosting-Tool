# Network File Hosting Tool

Welcome to the Network File Hosting Tool! 🚀

This Python-based application is designed to quickly and easily host your files or directories over a network. With this tool, you can share your local files with anyone on your network using a simple HTTP server, and you don't need any complex web server software or 

installations. Here’s a detailed overview:

Simple Setup:

Just run the script and follow the interactive prompts to specify the directory or file you wish to share. If you select a file, the tool automatically accesses its parent directory. 🗂️

Automatic IP Detection:

The tool intelligently detects your machine’s local IP address to generate the correct URL for hosting. No hassle figuring out your network settings manually! 🌐

Custom Port Configuration:

You can choose any port you like (default is 8080) to run your server, making it flexible based on your network configuration. 🎛️

Built-in HTTP Server:

Leveraging Python’s built-in HTTP server, this tool serves your files directly, ensuring quick setup and a lightweight solution without external dependencies. 🔧

Easy Shutdown:

The server runs indefinitely until you manually stop it (using Ctrl+C). This makes it ideal for temporary file sharing sessions or quick demos. ⏹️

Usage Scenario:

Perfect for local file sharing within your office, classroom, or home network. Whether it’s project files, presentations, or just a quick demo, this tool lets you publish content with ease. 👩‍💻👨‍💻

User Friendly:

With clear prompts and error-handling, even beginners will find this tool super easy to use. Enjoy a smooth and straightforward hosting experience! 😊

Give it a try and make file sharing fast, fun, and efficient! 🎉

Happy Hosting! 🔥
